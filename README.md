## 📌 1. 愿景与设计支柱 (Vision & Pillars)

### 1.1 项目愿景
本项目旨在突破 Minecraft 原生战斗的数值瓶颈与动作限制，打造一套**“高机动、强博弈、无硬性限伤”**的硬核动作RPG底层框架。摒弃通过简单粗暴的“限伤”或“互秒”来平衡游戏的做法。

### 1.2 核心设计支柱
*   **风险与收益的极致博弈**：通过“暴击”、“心流”与“过载”状态机，将玩家推向绝境与爆发的边缘。
*   **能量经济闭环**：护盾与能量池不仅是防御手段，更是战斗节奏的控制阀（如“疲弱期”与“破盾保护”机制）。
*   **空间与概念级演绎**：利用底层向量运算与碰撞机制，还原“绝对防御”与“领域对撞”的压迫感。

## ⚙️ 3. 核心系统概览 (System Overview)

### 3.1 战斗动作与物理反馈 `[公开版可见]`
*   **设计原则**：弥补原生战斗的动作短板，引入格斗游戏级的战术位移与物理碰撞反馈。
*   **包含框架**：目标锁定机制、侧跳、后撤步、前突。同时包含基于重击（如暴击终结）的**特殊物理击飞与碰撞反馈机制**（为满足视觉表现力，将包含特定的环境互动彩蛋）。
*   *(注：位移距离与碰撞体积、实体飞行轨迹的区块加载处理待测试验证)*

### 3.2 能量体系与破盾保护 `[公开版可见]`
*   **设计原则**：基于六档“能量效率”体系，实现护盾恢复速度的动态变化。
*   **破防与溢出保护**：护盾碎裂将导致短暂的硬直（僵直）。为防止“断崖式秒杀”，引入了**破盾溢出减伤机制**（即护盾击碎瞬间，溢出的伤害将被施加极高比例的衰减），确保玩家在高压下拥有一定的生存容错率。此衰减机制拥有最高的计算优先级，不受其他伤害乘区影响。
*   **等级压制与绝境共鸣**：当能量池差距过大时，弱势方的术式与控制将受重创。但作为补偿，弱势方的体术暴击率将大幅提升（伤害虽被压制，但能快速积攒反击资源），并伴随特殊的绝望音效反馈。
*   *(注：具体的衰减比例与压制阈值等 Mock Data 仅在内部版公开)*

### 3.3 暴击机制（体术专属） `[公开版可见]`
*   **设计原则**：仅限体术攻击触发。摒弃纯随机，引入**伪随机保底算法（PRD）**，确保在固定挥拳次数内必定触发，优化玩家心流体验。
*   **心流状态**：暴击后概率进入“心流”。心流期间，暴击率大幅拔高，并随连击次数动态变化。
*   *(注：具体公式与概率分布：内部测试值，最终以代码为准)*

### 3.4 高压博弈：过载与脑伤 `[公开版可见]`
*   **设计原则**：释放终极技能后必伴随惩罚（技能封锁）。玩家可通过强制修复来缩短惩罚，但面临极高的“过载（脑伤）”风险。
*   **绝境反击与状态重置**：陷入过载后，常规输出大幅下降。但作为补偿，过载期间体术的暴击判定阈值极度放宽，鼓励近战肉搏强行清醒。同时，**成功解除过载状态后，将触发一次全量状态净化**（清除所有负面Buff），增加绝境翻盘的爽快感。
*   *(注：具体的过载判定概率与各项阈值：内部测试值，最终以代码为准)*

### 3.5 领域对撞与机制反制 `[公开版可见]`
*   **设计原则**：领域展开具有极高的能量消耗门槛。多领域重叠时，依据“空间优先级”法则进行判定（如范围优先）。
*   **反制手段**：设计“领域展延”等高级机制，允许玩家在敌方领域内短暂获得豁免。特殊遗物可通过承受控制来解析并削减甚至免疫领域效果。
*   *(注：内部版本包含友军/施法者规则的详细判定与PVP/PVE分表)*

### 3.6 术式框架与特殊遗物 `[公开版可见]`
*   **术式分级**：划分为单体爆发、范围切割、复合奥义、绝对防御等。单次极高能量消耗的技能将附带真实伤害（穿盾）。
*   **高阶遗物与反制**：
    *   **多态召唤与自适应机制**：包含 AI 寻路验证与受击轮转适应，动态获取抗性。
    *   **深度夺舍系统**：寄生遗物在提供力量的同时会争夺控制权；临界点将触发强制夺舍，需队友击败宿主或在独立空间付出代价方可夺回身体。
*   *(注：涉及深度网络同步与底层状态锁定，待网络/单机性能验证)*

### 3.7 动态难度适配系统 (Dynamic Difficulty) `[公开版可见]`
*   **设计原则**：为保证不同受众的体验，游戏开局将提供难度选择（不可更改）。
    *   **硬核（原著）难度**：遵循内部完整数值闭环，高压博弈，破盾即濒死，过载惩罚极高。
    *   **普通（容错）难度**：大幅优化玩家体验。包含：降低过载触发率、延长过载修复次数、削弱等级压制效果、提高暴击率及保底频率（但限制单次暴击伤害上限，防止数值膨胀）、延长心流状态时间、并削弱部分高强度视觉特效（降低性能压力与视觉疲劳）。

## 📊 4. 核心状态机总表 (State Machine)

| 状态名称 | 触发条件 | 持续/清除 | 互斥/关联规则 | 可见性 |
| :--- | :--- | :--- | :--- | :--- |
| **心流 (Zone)** | 暴击后概率触发 | 持续较短时间，连击维持 | 触发期覆盖常规暴击率 | 公开 |
| **疲弱期 (Exhaustion)** | 单场消耗能量达标 | 持续数秒 | 护盾受击加重，真伤比例上升 | 公开 |
| **熔断 (Burnout)** | 释放领域后强制触发 | 持续数分钟 | 封锁技能与领域 | 公开 |
| **过载 (Overload)** | 强行修复熔断概率触发 | 持续较长时间 | 与心流机制联动；封锁高伤技能；解除时全清Debuff | 公开 |
| **绝境共鸣** | 能量池被极度压制 | 压制期间常驻 | 暴击率大幅上升，但伤害被严酷压制 | 公开 |

*注：具体数值、状态机阈值及互斥优先级为内部核心机密，公开版省略。*

## 📖 5. 术语表 (Terminology)

| 中文术语 | 英文对照 | 释义 |
| :--- | :--- | :--- |
| **绝对防御** | Absolute Defense | 制造排斥力场，干涉实体运动轨迹的特殊空间技能。 |
| **心流** | Zone State | 高频暴击触发的超载战斗状态，大幅提升短时输出。 |
| **伪随机保底** | PRD (Pseudo-Random Distribution) | 一种概率递增算法，避免纯概率带来的极端非酋体验。 |
| **术式** | Technique | 泛指消耗能量释放的各类主动技能。 |
| **领域** | Domain | 大范围高强度的控制或伤害结界。 |
| **领域展延** | Domain Amplification | 一种高阶反制手段，用于在敌方领域内获得短暂豁免。 |
| **过载** | Overload | 强行修复熔断导致的脑部超负荷状态。 |
| **破盾溢出保护** | Shield Break Protection | 护盾碎裂时，对溢出伤害进行高强度衰减的底层保护机制。 |
| **等级压制** | Level Suppression | 双方能量池差距过大时，对弱势方施加的伤害与控制惩罚机制。 |
