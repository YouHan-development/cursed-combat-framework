## 📌 1. 愿景与设计支柱 (Vision & Pillars)

### 1.1 项目愿景
本项目旨在突破 Minecraft 原生战斗的数值瓶颈与动作限制，打造一套**“高机动、强博弈、无硬性限伤”**的硬核动作RPG底层框架。摒弃通过简单粗暴的“限伤”或“互秒”来平衡游戏的做法。

### 1.2 核心设计支柱
*   **风险与收益的极致博弈**：通过“暴击”、“心流”与“过载”状态机，将玩家推向绝境与爆发的边缘。
*   **能量经济闭环**：护盾与能量池不仅是防御手段，更是战斗节奏的控制阀（如“疲弱期”机制）。
*   **空间与概念级演绎**：利用底层向量运算与碰撞机制，还原“绝对防御”与“领域对撞”的压迫感。

## ⚙️ 3. 核心系统概览 (System Overview)

### 3.1 战斗动作与锁定系统 `[公开版可见]`
*   **设计原则**：弥补原生战斗的动作短板，引入格斗游戏级的战术位移。
*   **包含框架**：目标锁定机制、侧跳、后撤步、前突。 *(注：位移距离与碰撞体积处理待测试验证)*

### 3.2 能量体系与伤害结算优先级 `[公开版可见]`
*   **设计原则**：基于六档“能量效率”体系，实现护盾恢复速度的动态变化。
*   **破防惩罚**：护盾碎裂将导致短暂的硬直（僵直），期间阻断恢复。
*   **伤害优先级树**：采用严格的防御剥离机制（能量护盾 -> 特殊法器护盾 -> 本体血量）。高阶术式附带的真实伤害具备最高穿透优先级，直接作用于本体。
*   **绝境共鸣（弱者悲鸣）**：当双方能量池差距过大（等级压制）时，弱势方常规术式与控制将受重创。但作为补偿，弱势方的体术暴击判定概率将大幅提升（尽管伤害被压制），并在触发时伴随特殊的绝望音效反馈。
*   *(注：具体恢复比例与压制阈值等 Mock Data 仅在内部版公开)*

### 3.3 暴击机制（体术专属） `[公开版可见]`
*   **设计原则**：仅限体术攻击触发。摒弃纯随机，引入**伪随机保底算法（PRD）**，确保在固定挥拳次数内必定触发，优化玩家心流体验。
*   **心流状态**：暴击后概率进入“心流”。心流期间，暴击率大幅拔高，并随连击次数动态变化。
*   *(注：具体公式与概率分布：内部测试值，最终以代码为准)*

### 3.4 高压博弈：过载与脑伤 `[公开版可见]`
*   **设计原则**：释放终极技能（领域展开）后必伴随惩罚（技能封锁）。玩家可通过强制修复来缩短惩罚，但面临极高的“过载（脑伤）”风险。
*   **绝境反击机制**：一旦陷入过载，常规输出大幅下降。但作为补偿，过载期间体术的暴击判定阈值会被极度放宽。这鼓励玩家在濒死绝境中，放弃远程法术，选择用极端的近战肉搏来强行清醒（暴击可大幅缩短过载时间）；若在过载期间成功进入“心流”，则会解锁一种效果减半的“残缺治愈”。
*   *(注：具体的过载判定概率与各项阈值：内部测试值，最终以代码为准)*

### 3.5 领域对撞与机制反制 `[公开版可见]`
*   **设计原则**：领域展开具有极高的能量消耗门槛。多领域重叠时，依据“空间优先级”法则进行判定（如范围优先）。
*   **反制手段**：设计“领域展延”等高级机制，允许玩家在敌方领域内短暂获得豁免。同时，具备“解析适应”能力的特殊遗物，可通过承受控制来解析并大幅削减甚至免疫领域的效果。
*   *(注：内部版本包含友军/施法者规则的详细判定与PVP/PVE分表)*

### 3.6 术式框架与特殊遗物 `[公开版可见]`
*   **术式分级**：划分为单体爆发、范围切割、复合奥义、绝对防御等。
*   **特殊规则**：单次技能消耗极高能量时，将附带不可阻挡的真实伤害（穿盾）。
*   *(注：地形破坏、区块挤压等具体破坏半径待碰撞/网络/单机性能验证)*

### 3.7 高阶遗物与特殊反制 `[实验性/待验证]`
*   **多态召唤与自适应机制 (Multi-state Summoning & Adaptation)**：针对传统召唤物容易变成“呆瓜”的问题，设计了包含 AI 寻路验证的多态召唤体系。同时，引入了“受击轮转适应”机制（含对控制系技能的解析适应），单位在承受特定类型攻击时会动态获取抗性，直至完全免疫（需通过高频伤害或特定机制强行击碎其适应核心）。
*   **深度夺舍系统 (Possession System)**：
    *   **寄生与代价**：玩家获取特殊遗物后，将获得力量提升，但同时会被寄生。随着遗物叠加，寄生体会在特定时刻争夺控制权，导致玩家不受控制地掉血。
    *   **终极危机**：当遗物达到临界值，寄生体将强制夺取玩家身体，玩家将被拉入独立空间，所有术式被封锁。
    *   **生死营救**：多人游戏下，队友需击败被夺舍的 AI 宿主以解救玩家；单人模式下，则需付出极高代价（如陷入长期重伤）才能夺回身体。
*   *(注：涉及深度网络同步与底层状态锁定，待网络/单机性能验证)*

## 📊 4. 核心状态机总表 (State Machine)

| 状态名称 | 触发条件 | 持续/清除 | 互斥/关联规则 | 可见性 |
| :--- | :--- | :--- | :--- | :--- |
| **心流 (Zone)** | 暴击后概率触发 | 持续较短时间，连击维持 | 触发期覆盖常规暴击率 | 公开 |
| **疲弱期 (Exhaustion)** | 单场消耗能量达标 | 持续数秒 | 护盾受击加重，真伤比例上升 | 公开 |
| **熔断 (Burnout)** | 释放领域后强制触发 | 持续数分钟 | 封锁技能与领域 | 公开 |
| **过载 (Overload)** | 强行修复熔断概率触发 | 持续较长时间 | 与心流机制联动；封锁高伤技能 | 公开 |
| **残缺治愈** | 过载期间触发心流 | 随特定机制解锁 | 治疗量大打折扣 | 公开 |
| **绝境共鸣** | 能量池被极度压制 | 压制期间常驻 | 暴击率大幅上升，但伤害被严酷压制 | 公开 |

*注：具体数值、状态机阈值及互斥优先级为内部核心机密，公开版省略。*

## 📖 5. 术语表 (Terminology)

| 中文术语 | 英文对照 | 释义 |
| :--- | :--- | :--- |
| **绝对防御** | Absolute Defense | 制造排斥力场，干涉实体运动轨迹的特殊空间技能。 |
| **心流** | Zone State | 高频暴击触发的超载战斗状态，大幅提升短时输出。 |
| **伪随机保底** | PRD (Pseudo-Random Distribution) | 一种概率递增算法，避免纯概率带来的极端非酋体验。 |
| **术式** | Technique | 泛指消耗能量释放的各类主动技能。 |
| **领域** | Domain | 大范围高强度的控制或伤害结界。 |
| **领域展延** | Domain Amplification | 一种高阶反制手段，用于在敌方领域内获得短暂豁免。 |
| **疲弱期** | Exhaustion | 能量消耗过度后导致的防御薄弱期。 |
| **过载** | Overload | 强行修复熔断导致的脑部超负荷状态。 |
| **熔断** | Burnout | 释放终极技能后，强制陷入的技能封锁与冷却状态。 |
| **残缺治愈** | Incomplete Healing | 处于过载状态时，通过触发心流解锁的受限治疗能力。 |
| **等级压制** | Level Suppression | 双方能量池差距过大时，对弱势方施加的伤害与控制惩罚机制。 |
